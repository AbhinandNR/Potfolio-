## 📖 About The Project

This portfolio is built to highlight my professional journey, including my full-stack web development internship experience, technical skills, and academic background. It features a modern, responsive design with smooth animations and interactive components.

### ✨ Key Features

- **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
- **Dynamic Sections:** Includes About, Skills, Projects, Resume, Certifications, and Contact sections.
- **Modern UI/UX:** Clean aesthetics, subtle micro-animations, and a professional color palette.
- **Downloadable Resume:** Users can easily view and download my digital resume directly from the site.

## 💻 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (v14 or higher)
- npm (Node Package Manager)

### Installation

1. **Clone the repo**
   ```sh
   git clone https://github.com/AbhinandNR/portfolio.git
   ```
2. **Navigate to the project directory**
   ```sh
   cd portfolio
   ```
3. **Install NPM packages**
   ```sh
   npm install
   ```
4. **Start the development server**
   ```sh
   npm start
   ```

The application will run on `http://localhost:3000`.
